GrapheneOS is a security-hardened Android distribution for Pixel devices. It
adds extensive exploit mitigations, a hardened memory allocator, sandboxed
Google Play, and stronger permission controls.

GrapheneOS distributes builds only through its own infrastructure to protect
integrity and signature verification — install via the official web installer.
