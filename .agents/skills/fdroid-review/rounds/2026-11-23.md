## Findings

**Usuals** — typed add with automatic aisle grouping; check-off; `Finish shop`
→ `Saved 1 item as a shop`; `Undo` restored exactly; History dated trip;
stats + "Your recent usuals"; barcode `3017620422003` → Nutella from Open Food
Facts with ODbL attribution and `Nutri-Score E`. Network: zero connections in
offline use; the only host ever seen was `world.openfoodfacts.org` (DNS 53 +
HTTPS 443), only after enabling the opt-in lookup. CAMERA and RECORD_AUDIO
requested on use, both refusals degrade gracefully. `FOREGROUND_SERVICE`,
`RECEIVE_BOOT_COMPLETED`, `WAKE_LOCK` traced to androidx.work — reminders
(`di/PreferenceReminders.kt:31-40`) and, when signed in, a 15-minute periodic
sync (`di/ListSyncScheduler.kt:29-30`).

**Spunto** — note save, checklist as a real checkable row, `#label`
recognised, offline keyword search, markdown toolbar, system photo picker.
Network: zero connections for the whole session (no server paired). CAMERA is
the pairing-QR scanner with paste fallback (`LoginScreen.kt:70,106`);
RECORD_AUDIO on use with an in-app fallback; `USE_BIOMETRIC` backs the optional
app lock.

Both: custom adaptive icons, valid categories (`Shopping List`, `Note`), no
ToS, English, no WebView, no self-update, `FATAL=0 ANR=0`, no
`MANAGE_EXTERNAL_STORAGE`. Code Quality: 13 and 14 entries, all informational,
R8 marker present on both.
